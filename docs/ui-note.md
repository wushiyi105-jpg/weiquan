# UI 说明：维权

- **谁在什么时刻打开**：给要退货、退款或投诉的人。
- **首屏任务句**：现在，先补哪项证据。
- **主操作**：按「还原售后经过 → 对上每项证据 → 生成投诉草稿」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：案卷与时间线；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：案卷与时间线。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给要退货、退款或投诉的人：订单、商品页和对话放进同一条时间线，每条主张挂上证据，规则注明渠道与地区。
